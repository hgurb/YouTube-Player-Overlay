# Privacy policy — YouTube Player Overlay

Last updated: October 28, 2026

YouTube Player Overlay saves only your enable/disable preference, overlay opening mode, player size, and background darkness in Chrome's local extension storage on your device. These preferences are not synced by the extension.

Your light/dark interface preference is stored locally in the extension's localStorage. The appearance popup reads the same preference set by the settings page. The GitHub credit is an ordinary external link; it only opens GitHub when clicked.

While an overlay is open, the extension temporarily remembers the current YouTube page address and scroll position in that page's memory so it can return you to browsing. It does not persist your browsing or playback history.

It also temporarily copies the source page's feed renderer data, including its current recommendations and loaded continuation items, to restore the same feed after closing. This snapshot stays in page memory only and is released after the return settles, when you interact with the feed again, or when you leave the page. It is not saved or transmitted.

The video's title, publication date, and view or watching count are read from YouTube's current player/page and displayed around the overlay. This information stays temporarily in page memory and is not saved or transmitted by the extension.

The extension does not operate servers, send analytics, sell data, or transmit data to its developer. Videos play through YouTube's regular player; YouTube's own terms, account settings, and privacy practices still apply.

Uninstalling the extension removes its saved preferences. Publisher contact information will be added before public distribution.
