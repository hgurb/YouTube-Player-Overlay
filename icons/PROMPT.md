# Extension icon

Created with the built-in image generation tool. Original artwork: `icon-master.png`. Chrome PNG assets: 16, 24, 32, 48 and 128 pixels, resized with Pillow using Lanczos sampling and preserving alpha.

## Generation prompt

Use case: logo-brand. Create a polished minimalist Chrome extension icon for 'YouTube Player Overlay', no text. One isolated square app icon on transparent background. Charcoal rounded square tile, with two overlapping video-window rectangles: a muted gray thin outline window offset toward upper left behind, and a large vivid coral-red (#ff404b) rounded rectangular floating video player in front centered slightly lower right, with a bold white play triangle at its center. The front player should be large and dominate the tile, simple instantly readable geometry at 16 pixels. Flat vector-like graphic, crisp clean edges, no texture, no 3D, no glossy effects, no tiny interface details, no watermark, no letters. Balanced composition, tile fills about 90% of square canvas. Actual transparent exterior outside the charcoal rounded tile. Single finished icon, not a sheet or mockup.
